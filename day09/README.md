# 学生管理系统

用 C 语言实现的学生信息管理系统，基于单向链表存储数据。

## 功能

- 添加学生（学号唯一，成绩 0~100）
- 删除学生（按学号）
- 修改学生（按学号）
- 按学号查找
- 按姓名查找（支持同名）
- 按成绩排序（从高到低）
- 保存到文件 / 从文件加载
- 菜单交互

## 编译运行

make
./app

## 项目结构

day09/
├── include/student.h   结构体和函数声明
├── src/student.c       链表操作、文件 I/O、排序
├── src/main.c          菜单循环
├── Makefile
└── README.md

## 技术点

- 单向链表：头插、尾插、删除、遍历
- 文件 I/O：fopen / fprintf / fscanf / fclose
- 字符串处理：strcmp、strcpy
- 排序：冒泡排序（交换数据）
- 输入校验：学号重复、成绩范围、缓冲区清空
- 多文件工程 + Makefile

## 已知不足（可扩展）

1. 尾插法 O(n)，可用 tail 指针优化到 O(1)
2. 排序交换数据，大数据量时字符串拷贝开销大
3. 查找是线性遍历，可用哈希表优化
4. 没有持久化索引，每次加载全量重建链表
